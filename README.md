# full-stack-bootcamp

This project was built while completing the [Complete Web Development in One Course with Modern Stack - JavaScript, Node.js, React, MongoDB, Linux and lots more!](https://www.udemy.com/course/complete-full-stack-web-development-bootcamp/) Udemy course.

## Calculator

A functional web-based calculator built with HTML, CSS, and vanilla JavaScript.

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Decimal number support
- Clear/reset functionality
- Error handling for division by zero

## Getting Started

Open `index.html` in your browser.
